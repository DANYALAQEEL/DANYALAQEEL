# Web Developer & UI Design Resource Toolkit

This skill equips the agent with direct knowledge of top-tier UI design, component, developer resource, and prototyping tools.

---

## 🎨 1. UI Inspiration
- **Mobbin**: Real-world app screens and UI inspiration from top mobile and web products.
- **Dribbble**: High-level design inspiration for landing pages, dashboards, micro-interactions, and hero sections.
- **Landingfolio**: Clean, modern landing page references and section layouts.

---

## 🧩 2. Free & Pro Components & UI Libraries
- **Animmaster Lib** ([animmasterlib.dev](https://animmasterlib.dev)): 300+ PRO-level animated UI components for modern web products (WebGL shaders, GSAP/Three.js scroll animations, 3D physics effects, Awwwards-style hero sections, mouse effects, SVG morphing).
- **UIverse**: Free copy-paste CSS/HTML components for animated buttons, glassmorphic cards, loaders, and inputs.
- **Aceternity UI**: Premium-looking React + Tailwind components with advanced visual effects (canvas animations, subtle gradients, 3D cards).
- **Shadcn UI**: Modern, accessible, headless component starter for React and Next.js.

---

## 🛠️ 3. Developer Resources & APIs
- **Public APIs**: Curated GitHub list of free public APIs for building projects, demos, and integrations.
- **Awesome Lists**: Master GitHub lists covering programming languages, frameworks, security, and developer topics.
- **free-for.dev**: Comprehensive directory of free tiers for SaaS, cloud hosting, databases, APIs, and dev tools.

---

## ⚡ 4. AI Prototyping & Browser Tools
- **v0 by Vercel**: AI-powered generative UI tool for prototyping React/Tailwind components from text prompts.
- **React Bits**: Animated UI components, background patterns, and interactive micro-effects for modern React interfaces.
- **Can I use**: Essential cross-browser support table for modern CSS, HTML5, and JavaScript features.

---

## 💡 Practical Application Rules:
- When building frontend web apps in Antigravity requiring Awwwards-level polish, draw animation patterns from **Animmaster Lib** (GSAP, Three.js shaders, 3D physics, SVG morphing).
- Combine **Aceternity UI** visual effects with **Shadcn UI** accessibility standards.
- Use **UIverse** CSS patterns for eye-catching buttons and card hover states.
- Always check **Can I use** compatibility when implementing bleeding-edge CSS features like `@container` queries or view transitions.
