A branch cut for a branch 𝑓1 of a multiple-valued function 𝐹is a 
portion of a curve that is excluded from the domain of 𝐹so that 𝑓1 is 
continuous on the remaining points.

Branch Point
A point with the property that it is on the branch cut of every 
branch is called a branch point of 𝐹.

The point 𝑧= 0 is common to each branch of the multiple-
